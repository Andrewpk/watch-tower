# Security Policy

## Supported versions

Security fixes are made against the latest release and the `main` branch. Older releases do not receive fixes, so please upgrade to the latest release before reporting.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, pull requests or discussions.

Report them privately through GitHub:

1. Go to the [Security tab](https://github.com/Andrewpk/watch-tower/security) of `Andrewpk/watch-tower`.
2. Click **Report a vulnerability**, or open the [advisory form](https://github.com/Andrewpk/watch-tower/security/advisories/new) directly.
3. Describe the issue, the affected version or commit, and steps to reproduce. A proof of concept helps.

Only the maintainer and GitHub can see the report.

## What to expect

Watch Tower is maintained by one person in their spare time, so there are no formal SLAs. As a rough guide, you can expect an acknowledgement within a week. After that we will confirm the issue, work on a fix and agree a disclosure date with you. Reporters are credited in the advisory unless they prefer not to be.

## Scope

This policy covers the Watch Tower code in this repository and the Docker image published from it. Vulnerabilities in Laravel, Nightwatch or other third-party packages should be reported to those projects.
